# FFmpeg in Present

Present decodes video with FFmpeg (https://ffmpeg.org), used under the GNU
Lesser General Public License, version 2.1 or later. FFmpeg's licence
(`COPYING.LGPLv2.1`), its licence summary (`LICENSE.md`) and the exact source
and build options (`FFMPEG-SOURCE.txt`) are in this folder.

FFmpeg is included as separate shared libraries, unmodified, and can be
replaced with a compatible build of your own.

**Its source is published with Present**, as `ffmpeg-<version>.tar.xz` beside
the download this copy came from, matching the checksum in
`FFMPEG-SOURCE.txt`. If you have Present without it, ask whoever gave you this
copy, or the contact at https://present.multivrs.space, and it will be
provided. FFmpeg is a trademark of Fabrice
Bellard, originator of the FFmpeg project.
